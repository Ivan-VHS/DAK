# Duck Shell native design transfer

**Status:** implemented in the optional Qt 6 host-native Mora adapter; kernel-owned desktop integration remains pending.

**Panel source:** [Duck Shell Figma — frames 09–12](https://www.figma.com/design/1Hxe0LzJZbrllV5kjBj0Lm/Untitled?node-id=14-2)  
**Material source:** [Imperial Noir & Glass reference library](https://www.figma.com/design/RWjphsEdITgECaS8G31o9H/Untitled?node-id=0-1)

## Native surfaces

| Figma frame | Native entry point | Implemented behavior |
|---|---|---|
| 09 — Window overview | `MoraWindow::openOverview()` | Enumerates visible Mora top-level windows, activates or closes a selected window. |
| 10 — Notification center | `MoraWindow::openNotifications()` | Displays events produced by native Mora window open/close actions, retains the latest 24 locally, and supports clearing the feed. |
| 11 — Quick settings | `MoraWindow::openQuickSettings()` | Persists a Mora-only quiet mode that suppresses new shell-generated notifications. Network, Bluetooth, audio/brightness and power controls are explicitly unavailable until host services are connected. |
| 12 — Application launcher | `MoraWindow::openAppLauncher()` | Searches the local `mora/apps.json` catalogue and opens selected entries through the existing native app-window factory. Catalogue command strings are never executed. |

The system bar exposes the four surfaces without replacing the existing home, catalogue, workspace pages or application dock. Keyboard access is available through Ctrl+Tab (overview), Ctrl+K / Ctrl+Space (launcher), Ctrl+Shift+N (notifications) and Ctrl+Alt+S (quick settings).

## Visual and interaction contract

The native adapter consumes the Imperial Noir & Glass tokens in `mora/theme.json`: `#050505` canvas, `#070707` shell, charcoal acrylic surfaces, white/graphite text and `#FFD700` as the only primary accent. The new reference library contributes folds, softened dune curves, layered circular forms and fine edge highlights; copper/orange source lighting is recoloured as low-opacity gold. The transfer does not introduce remote imagery, a remote stylesheet, web font, WebView, CDN asset or runtime network dependency.

Panels use native Qt widgets and host-managed top-level windows. Window overview actions call the existing Qt window lifecycle; launcher actions resolve only catalogue IDs already loaded by Mora. Local notification history and quiet-mode preferences use the existing DuckOS/Mora `QSettings` namespace.

## Verification

The `duckos-mora-native-smoke` self-test checks that the system actions exist, opens all four native panels, checks the quick-settings preference and non-empty launcher catalogue, and retains the three-independent-window smoke check. The dedicated native Mora workflow must pass on the branch before this slice is considered CI-verified.

## Explicit boundaries

This is a host-native shell implementation, not the DuckOS kernel desktop session. The panels do not create kernel windows, process sessions, IPC endpoints, virtual workspaces, a compositor, a capability broker or driver control. The host operating system still owns native window placement, focus, input and decorations.

Network, Bluetooth, audio, brightness and power controls are intentionally presented as unavailable instead of simulating hardware changes. The local quiet-mode preference affects only notifications generated by the Mora adapter. The launcher opens only existing native Mora app windows; it does not install packages, execute manifest commands or grant application capabilities.

The next kernel integration stage requires a process-backed desktop service, DABI64/IPC transport, native window descriptors, input/display services, and an enforced capability broker. The UI panels must consume those versioned service contracts only after they exist and are covered by integration tests.


## Material translation from the supplied reference library

| Reference family | Shell translation |
|---|---|
| Складки света | Low-contrast curved desktop folds and a few directional edge reflections behind content |
| Медное стекло | Translucent charcoal layers, ring-like clipping and thin gold rim light; no copper UI palette |
| Тихие дюны | Broad, quiet curves for workspace separation and empty states |
| Световые поля | Local radial light that gives elevation and focus to a panel without brightening the canvas |
| Пластика форм | Quarter-circle and overlapping rounded geometry for app glyph tiles and compact overview cards |
| Янтарная ночь | A restrained gold edge on active panels; the global token remains `#FFD700` |

These are native-drawn and CSS-rendered primitives, not full-frame bitmap wallpaper imports. The Qt host shell keeps foreground controls opaque enough for legibility; the browser surface treats backdrop blur as progressive enhancement. The reference library contains material images rather than UI component definitions, so the translation is intentionally structural rather than a literal screen clone.

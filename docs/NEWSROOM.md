# DuckOS Newsroom — «Вечерний курьер»

## Роль в системе

Newsroom — пользовательское приложение DuckOS для чтения актуальных материалов из
открытых RSS/Atom-лент. Интерфейс встроен в DuckOS Desktop Shell; агрегация и
обновление выполняются Python-службой в native/services/duckos_services/news.py.
Сетевой доступ не помещается в ядро и не выполняется через произвольные shell-команды.

## Источники

По умолчанию настроены бесплатные публичные RSS-ленты:

| Источник | Лента | Язык |
|---|---|---|
| BBC News Україна | https://feeds.bbci.co.uk/ukrainian/rss.xml | Украинский |
| The Kyiv Independent | https://kyivindependent.com/news-archive/rss/ | Английский |
| BBC News · Мир | https://feeds.bbci.co.uk/news/world/rss.xml | Английский |

RSS содержит заголовки, краткие описания, даты и ссылки. Полный материал открывается
на сайте издателя: приложение не копирует статьи целиком и сохраняет атрибуцию.
Наличие RSS не означает лицензию на повторную публикацию полного текста или фотографий.

## Запуск в режиме preview

Из корня репозитория:

    python -m http.server 4173 --directory desktop

В другом терминале:

    PYTHONPATH=native/services python -m duckos_services news serve

Откройте http://127.0.0.1:4173. В DuckOS Shell запустите приложение
«Вечерний курьер» через боковую панель, dock или Ctrl+K.

Сервис слушает только 127.0.0.1:8765 по умолчанию. Для других локальных портов
можно изменить --port. Привязка к публичному сетевому интерфейсу запрещена.

## CLI

    PYTHONPATH=native/services python -m duckos_services news status
    PYTHONPATH=native/services python -m duckos_services news refresh
    PYTHONPATH=native/services python -m duckos_services news serve --host 127.0.0.1 --port 8765
    PYTHONPATH=native/services python -m duckos_services po search news

Служба обновляет источники при старте и далее каждые пять минут. Кэш хранится
в ~/.local/state/duckos/news-cache.json; неудача одного источника не удаляет
последние успешно загруженные материалы из его кэша.

## API

- GET /api/news — лента, category, q, limit.
- GET /api/news/sources — список включённых источников.
- GET /api/news/health — состояние кэша и служб источников.
- POST /api/news/refresh — принудительное обновление; тело запроса должно быть пустым.

CORS разрешён только для локальных HTTP-origin. Источники заданы в коде и проверяются
по HTTPS-host allow-list; перенаправления на сторонние хосты отклоняются.
Размер ответа ограничен 2 MiB на источник, сетевой запрос — восемью секундами.
HTML из описаний преобразуется в обычный текст; DTD и entity declarations запрещены.
API не предоставляет proxy-fetch для URL, переданных клиентом, и не исполняет команды.

## Состояние и ограничения

- Категории выводятся эвристически из заголовка и краткого описания; это не редакционная
  классификация. Пользователь может фильтровать и искать по полученному тексту.
- Отметки «прочитано» и избранное хранятся в локальном профиле браузера оболочки.
- Если backend не запущен, UI показывает явный статус подключения и инструкцию запуска,
  а не выдуманные заголовки.
- В отсутствие сети отображается последний сохранённый кэш с временем обновления.
- Доступность конкретного RSS-источника зависит от сети и политики издателя; сбой
  одного источника не блокирует остальные.
- Этот адаптер является пользовательской службой и не частью freestanding kernel.

## Проверки

    PYTHONPATH=native/services python -m unittest discover -s native/services/tests -v

Тесты покрывают RSS/Atom parsing, allow-list ссылок, очистку описаний, лимиты,
кэширование, поведение при ошибке источника и локальную CORS policy.

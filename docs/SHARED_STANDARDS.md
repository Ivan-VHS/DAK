DAK hosts the canonical shared standards for the Ivan-VHS project ecosystem. Product repositories keep short local entry pages where a stable path is useful; their source code, tests, schemas and versioned profiles remain authoritative for local behavior.

## Governance

Update a shared rule here first. Keep product-specific implementation notes in the owning repository and link to the relevant local source, schema, tests and validation workflow. A shared policy document is not evidence that a project has implemented it.
